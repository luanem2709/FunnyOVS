SHOT BUILDER - LAM PHIM "WHAT IF" KHONG CAN AI
================================================

Shot Builder dung chinh bo dung hinh Remotion cua skill what-if-animation
(giay phep MIT), nen hinh giong het tap mau Rewind. Ban tu soan tung canh
bang giao dien: boi canh, goc may, nhan vat, tu the, bieu cam, do vat, chu
tren man hinh. Khong can AI, khong can ElevenLabs.
Ban tu lo kich ban, giong doc va ghep trong CapCut.


0. TAO VIDEO: LAM THEO 6 BUOC O COT TRAI, ROI BAM "TAO VIDEO"
-------------------------------------------------------------
Man hinh chia doi: cot trai la cac buoc, cot phai la danh sach canh + anh storyboard.
  (Tren cung) Tap phim: ten tap, bo hinh, mau phim, chuyen dong, nhan vat chinh.
  1. Kich ban (.txt)  - bam "Chon file kich ban .txt". Moi cau mot dong; dong trong
                        hoac dong bat dau bang # = sang doan moi.
  2. Giong doc        - chon 1 trong 2:
       + "Noi API tool giong noi bo": mo tool giong cua ban, bat che do API, bam
         "Ket noi", chon giong + toc do doc. Shot Builder chi gui file kich ban .txt
         sang tool giong; tool giong tu chia cau, ngat nghi va doc, roi tra ve file
         giong (.wav / .mp3) + phu de .srt.
       + "Tai len file giong co san": chon file .mp3 / .wav ban da co.
  3. Phu de SRT       - noi API: tu lay tu tool giong. Tai file giong: chon SRT neu co
                        (khop chinh xac nhat); khong co thi tool tu nghe giong de khop.
  4. Canh             - chon cach tao canh:
       + Chatbot dung canh (KHUYEN DUNG, dung duoc goi ChatGPT Plus / Gemini / Claude):
         bam "Sao chep lenh cho AI chat" -> dan vao chatbot -> luu JSON tra ve thanh
         file .json -> bam "Mo file canh". Chatbot chi can file txt, KHONG can SRT:
         tool tu khop tung canh voi SRT cua giong (doc nhanh hay cham deu khop).
       + Tool tu goi AI Gemini: API key mien phi (aistudio.google.com/apikey).
       + ChatGPT API / Claude API / API khac: can key API tra phi theo luong dung.
         Goi Plus/Pro cua ChatGPT, Gemini, Claude KHONG dung duoc cho API.
       + Offline: khong can mang, canh rat don gian (chi de thu).
  5. Chuyen canh + SFX - 27 kieu chuyen canh: lia, zoom, xoay, chop trang, mo den, glitch,
                        truot ngang/trai/tren xuong, day len, gat mau, gat cheo, khep tron,
                        vong mau, lat the, mo trang, rem soc, rung manh, nhoe, thu nho,
                        xoay xoay, cua khep mo, o vuong pixel, chay phim, khep trai tim,
                        khep ngoi sao, tia truyen tranh.
                        "Tu dong" chon theo noi dung va doi kieu cho khoi lap; "Tron ngau
                        nhien" dung tat ca. Ty le % canh co chuyen canh + SFX, am luong SFX,
                        chuan hoa am luong.
                        Kho SFX co san 104 file (khong ban quyen). "Kho SFX": nghe thu tung
                        file theo loai. "+ Them SFX...": chon loai roi chon file (chon nhieu
                        file cung luc), SFX cua ban duoc uu tien dung truoc, xoa duoc.
  6. Font + noi luu   - mac dinh luu video vao CUNG THU MUC voi file kich ban .txt.
Roi bam "Xem storyboard" (kiem tra hinh) hoac "TAO VIDEO".
Ket qua: <ten tap>.mp4 + <ten tap>.srt (+ <ten tap>_giong.wav/.mp3 neu dung tool giong).


GIAO THUC API CHO TOOL GIONG (danh cho nguoi lam tool giong)
------------------------------------------------------------
Tool giong mo may chu tren may (mac dinh http://127.0.0.1:7880):
  GET  /api/health          -> {"ok":true,"name":"...","version":"...","licensed":true}
  GET  /api/voices          -> {"voices":[{"id":"...","name":"..."}],"selected":"..."}
  POST /api/tts             <- {"text":"noi dung txt","txt_file":"duong dan .txt","voice":"id","speed":1.0,"title":"..."}
                            -> {"job":"abc"}
  GET  /api/job/abc         -> {"status":"running|done|error","progress":0..1,"message":"...","error":"..."}
  GET  /api/job/abc/audio   -> file am thanh (.wav / .mp3)
  GET  /api/job/abc/srt     -> file SRT
Tool giong chua kich hoat key: tra HTTP 402/403 + {"error":"..."}, Shot Builder hien nguyen van.
